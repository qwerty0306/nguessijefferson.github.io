# Jefferson Nguessi – Portfolio

Network Administrator & Security. React + Vite, no backend, bilingual (EN/FR).

- Edit all content in `src/data.js`
- Run locally: `npm install && npm run dev`
- Deploy: push to `main`. The workflow in `.github/workflows/deploy.yml` builds and publishes to GitHub Pages.
  In the repo go to Settings → Pages → Source: **GitHub Actions** (one time).
